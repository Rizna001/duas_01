# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024

### Added
- Initial release
- 45 categorized groups with 123 dua records in the current source data
- Supplementary Quranic and dhikr collections are documented and included in the generated API
- Support for 10 languages:
  - English
  - Arabic
  - Urdu
  - Bengali
  - Malay
  - Tamil
  - Malayalam
  - Turkish
  - Indonesian
  - French
- Color-coded UI for easy navigation
- Search functionality
- Responsive design for all devices
- Static JSON API for integration
- Offline capability
- Dua counter feature
- Copy to clipboard functionality
- Font size adjustment for Arabic text

### Categories Included
- Daily Worship (8 categories)
- Daily Life (7 categories)
- Sleep & Dreams (2 categories)
- Travel (1 category)
- Hajj & Umrah (1 category)
- Salawat & Dhikr (3 categories)
- Death & Funeral (1 category)
- Life Events (3 categories)
- Health & Hardship (3 categories)
- Protection (3 categories)
- Knowledge & Character (2 categories)
- Community (1 category)
- Weather (1 category)

### Special Features
- Asma ul Husna (99 Names of Allah)
- Asma ul Anbiya (25 Prophets)
- Multiple Salawat variations (Ibrahimiyyah, Nariyyah, Tunjina)
- Complete Hajj & Umrah duas
- Marriage and wedding duas
- Istikhara prayer dua
- Protection from evil eye

## Version History

### Version Naming Convention
- **Major** (x.0.0): Breaking changes, major new features
- **Minor** (0.x.0): New categories, languages, or features
- **Patch** (0.0.x): Bug fixes, translation corrections, UI improvements

### How to Update
```bash
git pull origin main
npm install
npm run build
```
